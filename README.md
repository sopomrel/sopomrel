### 📌 Featured projects

**[Cinema API](https://github.com/sopomrel/cinema-api)** — *Java · Spring Boot 3*
A production-oriented REST API for a movie catalog (movies, actors, directors). Layered architecture, DTOs, role-based Spring Security, internationalized error handling (Georgian / English), profile-based config (H2 in dev, PostgreSQL in prod), Actuator monitoring with **custom health indicators and metrics**, structured logging, and a full test suite (unit, integration, controller, repository) behind a JaCoCo coverage gate.

**[DuckieTown](https://github.com/sopomrel/FinalProject)** — *Python · Flask · Godot*
A team-built robotics education platform for the Duckiebot DB21J. Students program tasks that run in a Godot 4.6 simulation or on real hardware, controlled through Flask task servers with live MJPEG camera streaming, JSON status polling, runtime YAML configuration, and a CLI launcher that deploys tasks to robots over the network.
